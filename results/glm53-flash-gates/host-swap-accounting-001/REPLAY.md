# Unchanged profile replay after the unloaded control

The fixed unloaded control recorded 121 valid samples and no global or selected
cgroup swap activity. This justifies one fresh environmental replay of the
existing full-context experimental profile. It does not reopen the two failed
startup reclamation alternatives or create a third allocator variant.

Keep the exact current model, runtime, startup flags, batch 512, threshold 128,
four 262,144-token slots, 1,048,576 aggregate cap, containment, watchdog, fixture
generator, smoke, necessary window, full-duration client and scorers. No service,
swap-policy, privilege or production-default changes are part of this replay.

Freeze clean source, runtime/model inventories, prepared cache and the external
observer before obtaining verified later public randomness and fresh fixtures.
The new freeze script is a copy of the preceding closed freeze with only its
output, scope and additional evidence-source bindings changed.

Retain the broad pre-freeze global baseline. Any swap-in/out or used-swap change
still fails the host gate, including changes outside the model cgroup. The quiet
control cannot reset that baseline. Observe phases through stop and post-run
verification. Avoid optional auxiliary service queries while GLM is loaded.

Capture direct cgroup accounting with the explicit external observer for the
first 900 seconds; retain exact temporal coverage. Whole-host watchdog and model
identity/cgroup observations continue throughout any longer run. Do not sum
nested cgroups or use ownership counters to exempt paging. An event beyond the
external observer's endpoint remains unattributed by that diagnostic.

Admit the unchanged 1,800-second full-duration workload only after authenticated
startup, smoke, the complete necessary window, unchanged compiled inputs, native
identity/containment checks and the broad host gate all pass. Stop on an observed
failure, preserve it and the clean-stop evidence, and do not run the full workload
after a failed prerequisite. Direct context, fidelity, media, production switching
and qualified speed remain separate unfinished requirements.
