

1. Identify the relevant tables: customers and orders.
2. Join them on customer_id.
3. Aggregate total order value per customer.
4. Order by total descending, limit to 5.

```sql
SELECT
    c.customer_id,
    c.name,
    SUM(o.order_value) AS total_order_value
FROM
    customers c
JOIN
    orders o ON c.customer_id = o.customer_id
GROUP BY
    c.customer_id, c.name
ORDER BY
    total_order_value DESC
LIMIT 5;
```

- `JOIN` links each order to its customer.
- `SUM(o.order_value)` computes each customer's total.
- `GROUP BY` aggregates per customer.
- `ORDER BY ... DESC` + `LIMIT 5` returns the top 5.
